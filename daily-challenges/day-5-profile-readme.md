# Day 5: Creating Terminal Aliases

## Objective
Learn how to create aliases for frequently used terminal commands.

## Commands

### 1. Create an alias for listing files
```bash
alias ll='ls -la'
```

### 2. Create an alias for clearing the terminal
```bash
alias cls='clear'
```

### 3. Create an alias for navigating to the home directory
```bash
alias home='cd ~'
```

### 4. View existing aliases
```bash
alias
```

### 5. Remove an alias
```bash
unalias ll
```

## What I learned
I learned how aliases create shorter names for frequently used commands, making terminal work faster and more convenient.
