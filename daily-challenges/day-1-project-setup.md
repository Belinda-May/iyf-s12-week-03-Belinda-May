# Day 1: Project Setup

## Objective
Practise creating folders and files using the terminal.

## Commands

```bash
mkdir -p practice-project/css practice-project/js practice-project/images
touch practice-project/index.html
touch practice-project/css/style.css
touch practice-project/js/script.js
```

## What I learned
I learned how to use `mkdir` to create directories and `touch` to create files. I also learned how to organize a project into folders for HTML, CSS, JavaScript and images.
